# 自定义视觉素材文件夹 (Custom Assets Directory)

后续上传的按钮切图、缺省插画、角色贴纸、图标等可放入此目录，例如：
- `hero_boy.png` — 首页盒子头漫游者小男孩主视觉
- `empty_diary_net.png` — 日记空状态（小男孩拿捕虫网网星星）
- `empty_feeding_bottle.png` — 喂养空状态（巨大空玻璃奶瓶）
- `tab_planet.png` / `tab_diary.png` / `tab_settings.png` — 底部导航按钮切图
- `mood_*.png` / `weather_*.png` — 心情与天气手绘图标
