# 自定义字体文件夹 (Custom Fonts Directory)

请将你的字体文件（支持 `.woff2`、`.ttf`、`.otf`）放入此目录，例如：

- `display.woff2` — 手写/绘本风标题字体（用于「未知漫游者的登陆手帐」、「星光碎片」等主标题）
- `body.woff2` — 正文字体（用于日记正文、卡片文字、表单标签）
- `mono.woff2` — 打字机/等宽数字字体（用于顶部日期 `2025.11.18 Tue.`、奶量/身高数值）

放入文件后，在 `src/index.css` 顶部的 `@font-face` 占位区域取消注释并对应文件名即可全局生效。
