# 自定义字体上传目录 (`/public/fonts`)

你可以直接把字体文件（支持 `.ttf`、`.otf`、`.woff2`、`.woff`）上传到以下位置，**无需改文件名，刷新页面即可自动生效**：

1. **替换全局正文（目前的类似黑体字体）**：
   - 直接上传到 `/public/fonts/` 根目录，或上传到 `/public/fonts/body/` 文件夹内。
2. **（可选）替换手绘标题字体**：
   - 上传到 `/public/fonts/display/` 文件夹内（用于「未知漫游者的登陆手帐」、「星光碎片」等大标题）。
3. **（可选）替换日期与数字等宽字体**：
   - 上传到 `/public/fonts/mono/` 文件夹内（用于日期、奶量、体温、身高体重等数值）。

> 提示：如果只上传了 1 个通用圆体/手写体文件，直接放进 `/public/fonts/body/`（或 `/public/fonts/` 根目录）即可替换全站所有类似黑体的默认文字。
