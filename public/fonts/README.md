# 自定义字体上传目录 (`public/fonts`)

支持 `.ttf`、`.otf`、`.woff2`、`.woff` 格式，支持中文文件名，**直接拖入后刷新页面即可自动生效**：

- **`public/fonts/body/`**（或直接拖入 `public/fonts/` 根目录）
  - **替换全站除一级手绘大标题以外的所有文字**（包括正文、卡片标题、按钮、标签、副标题、日期、数值与输入框等）。
  - 首页「〇〇的登陆手帐」及各模块「星光碎片」「观测坐标」「能量喂养」「治愈工坊」「星际档案」等一级艺术大标题会**完整保留原有手绘标题字体**，不受影响。
- **`public/fonts/display/`**（选填）
  - 仅在你也想替换上述一级手绘大标题字体时再放入。
- **`public/fonts/mono/`**（选填）
  - 仅在你想单独为日期与数字指定另一款字体时再放入。
