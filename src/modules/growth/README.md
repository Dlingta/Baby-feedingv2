# 观测坐标 · Growth（0～36 月龄婴幼儿成长监测与专业营养评价模块）

本模块为「宝宝登陆手帐」的独立核心板块，与首页、日记本、喂养、治愈工坊同级，提供 **成长走势与历史（4.1）**、**专业营养评价（4.2）** 与 **新建/编辑成长记录（4.3）** 三个互联子页面，共享宝宝档案、测量数据、WHO 2006 LMS 参考数据与营养评价计算引擎。

## 2. 路由与页面说明

模块同时与主应用状态及 Hash 路由双向同步：

- `#/growth/overview`（原型编号 `4.1`）：**成长 · 走势与历史**
  - 动态读取宝宝档案（缺少出生日期时展示「等待建立星球连接……」与档案引导入口）。
  - 统一 `身高 / 体重 / 头围` 切换 Tab，共用一个交互式 SVG 图表，实时切换纵轴单位、宝宝金黄色星星折线与对应性别 WHO 0～36 月龄 `-2SD / -1SD / Median / +1SD / +2SD` 动态参考曲线。
  - 支持点击星星节点弹出奶油色读数气泡（真实 Z-score、百分位数与参考区间）、触摸拖拽平移、缩放与重置视野。
  - 展示「最近一次成长记录」及与前一次有效记录的真实差值变化、历史测量列表（查看详情快照 / 编辑 / 删除）与右上角记录日历抽屉。
- `#/growth/assessment`（原型编号 `4.2`）：**成长 · 专业营养评价**
  - 顶部综合评价卡 + 显著医学免责声明。
  - 四项核心指标独立计算与展示：`年龄别体重（WAZ）`、`年龄别身长/身高（LAZ）`、`身长/身高别体重（WLZ：0～24m 用 wfl，24～36m 用 wfh）`、`年龄别 BMI（BMIZ）`，均配独立科普说明弹窗及「颜色 + 文字」状态标识。
  - `年龄别头围（HCZ）` 单独列为发育监测区域，绝不混入体重营养分级。
  - 国家卫健委 **0～3 岁 9 次关键月龄随访日历**（`1、3、6、8、12、18、24、30、36 月龄`）。
  - 底部「这些参考曲线从哪里来？」数据溯源说明，并内置「切换为参考数据未加载态」测试按钮以验证错误降级 UI。
- `#/growth/entry`（原型编号 `4.3`）：**成长 · 新建/编辑成长记录**
  - 测量日期选择（默认拦截未来日期，可显式开启「特殊数据导入」；始终拦截早于出生日期的录入）。
  - 身高（cm）、体重（kg）、头围（cm）小数输入，支持仅填部分项目保存（并给出明确提醒，绝不将缺失项误判为正常）。
  - 测量方式（卧位 / 立位）选择器，按月龄给出 WHO 推荐提示；保存原始输入值，评估时按 WHO 2006 规范进行无损 `±0.7 cm` 换算并注明说明。

## 3. 专业参考标准与医学安全边界

1. **参考数据来源**：通过本地离线包 `who-growth-standards` 加载官方 **WHO Child Growth Standards (2006)** 分性别按日龄/按 0.1cm 步长的完整 LMS 表（`wfa`、`lhfa`、`hcfa`、`bfa`、`wfl`、`wfh`），严禁杜撰或使用静态水平参考线。
2. **指南阈值区分**：
   - `WAZ`：`< -2SD` 低体重，`< -3SD` 重度低体重；不用于单独判定超重/肥胖。
   - `LAZ`：`< -2SD` 生长迟缓，`< -3SD` 重度生长迟缓。
   - `WLZ` & `BMIZ`：严格区分国家卫生健康委《婴幼儿营养喂养评估服务指南（试行）》边界（`> +1SD ～ +2SD` 超重、`> +2SD` 肥胖、`< -2SD` 消瘦）与 WHO 2006 0～5 岁措辞差异（`> +1SD` 超重风险、`> +2SD` 超重、`> +3SD` 肥胖），并在卡片及详情中明示。
   - `HCZ`：独立用于颅脑与神经发育监测，不参与营养不良/超重肥胖分级。
3. **缺省与早产儿安全护栏**：
   - 缺少生理性别（`boy`/`girl`）、缺少出生日期、缺少必要测量值或参考数据未加载时，一律返回「数据不足 / 参考数据未加载」，绝不输出虚构结论，也绝不因仅单项正常就将整体评为「参考区间内」。
   - 标记为早产儿（胎龄 `< 37 周`）且处于 0～24 月龄窗口时，系统按实际月龄保留计算留档并将综合结论标为「待核实」，提示由儿童保健医生确认校正年龄规则，绝不擅自覆盖实际月龄。

## 4. 运行单元测试

```bash
npx tsx --test src/modules/growth/__tests__/growthCalculations.test.ts
```

测试覆盖：闰年与跨月精确日龄/月龄计算、WHO LMS 公式（`L != 0` / `L == 0` / `|Z| > 3` 尾部修正 / 反向曲线）、正态分布百分位极值防溢出、立/卧位 `±0.7 cm` 无损转换、表单校验规则、各类营养评价边界（正常/低体重/生长迟缓/消瘦/超重/肥胖）、缺性别阻断、参考数据未加载态、早产儿护栏、头围独立隔离与部分录入防误判。
